# MoreMore Mooncake (Double) — 更多月饼·双馅

An **independent addon** for the [More Mooncake](https://github.com/Euuuuuurus/more-mooncake) mod.
It adds **double-filling mooncake slices**: pick any two of 12 single fillings (66 combinations,
C(12,2)), each available in the full copper-style lifecycle of 8 states (fresh / rusted /
weathered / oxidized + the waxed variant of each) — **528 items in total**.

| 平台 | Minecraft | 状态 |
|---|---|---|
| Fabric | 1.21.1 | ✅ |
| NeoForge | 21.1.238 | ✅ |

## Features

- **66 two-filling combos**: 莲蓉、豆沙、枣泥、五仁、椰蓉、百果、黑芝麻、板栗、紫薯、芋泥、水果、绿豆沙 — any pair becomes a double mooncake.
- **Double = sum of both fillings**: the food applies *both* fillings' signature status effects at once, and the slice colour is the blend of the two fillings.
- **8 copper-style states per combo**: oxidize (rust → weathered → oxidized), wax with honeycomb to preserve (doubled effect duration, no side effects), scrape with an axe to undo either.
- **Full base-mod integration** through the base `MooncakeFood` extension point:
  - assemble 8 slices + 1 egg into a **grand mooncake** (any mix of base and addon slices),
  - placed grand mooncakes render the slice colours, eat in clockwise slice order,
  - cut a placed grand mooncake with an axe to get the slices back.
- **JEI integration** (soft dependency): a dedicated *Double-Filling Combos* category lists all 66 combinations, and addon slices appear in the base mod's *Assembly* / *Scrape* JEI categories.
- **Survival-friendly recipes**: slice craft (wheat + two filling ingredients → 2 slices), wax (honeycomb), oxidize (iron nugget / copper ingot / copper block), plus axe scrape.

## Requirements

- Minecraft **1.21.1**
- The base mod **More Mooncake 1.0.0** (Fabric or NeoForge build)
- **Architectury API 13.0.8**
- Fabric: **Fabric Loader 0.16.10+** and **Fabric API**
- NeoForge: **NeoForge 21.1.238+**
- Optional: **JEI 19.57** for recipe viewing

## Build

Requires JDK 21.

```bash
# Linux / macOS
./gradlew build
# Windows
gradlew.bat build
```

The addon compiles against the base mod's common jar. Place it at `libs/more-mooncake-common.jar`
(build it from the [More Mooncake](https://github.com/Euuuuuurus/more-mooncake) repo:
`./gradlew :common:jar`), or adjust the `modCompileOnly files(...)` path in the module
`build.gradle` files.

Outputs:

```
fabric/build/libs/moremooncake-addon-fabric-1.0.0.jar
neoforge/build/libs/moremooncake-addon-neoforge-1.0.0.jar
```

## Install

Put the addon jar **and** the matching base mod jar into `mods/`:

- Fabric: `moremooncake-addon-fabric-1.0.0.jar` + `more-mooncake-fabric-1.0.0.jar`
- NeoForge: `moremooncake-addon-neoforge-1.0.0.jar` + `more-mooncake-neoforge-1.0.0.jar`

Plus Architectury API (and Fabric API on Fabric, NeoForge itself on NeoForge). Optional: JEI.

## Resource generation

All 528 textures, models, language entries and recipes are generated by
[`tools/AddonResourceGen.java`](tools/AddonResourceGen.java):

```bash
java tools/AddonResourceGen.java .
```
